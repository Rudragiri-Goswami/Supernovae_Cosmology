# Supernovae Cosmology

### Measuring Cosmological Parameters Using Type Ia Supernovae

## Overview

This project uses the **Pantheon+SH0ES** Type Ia supernova dataset to study the expansion of the Universe.

The analysis focuses on the relationship between redshift and distance modulus and uses a flat **ΛCDM model** to estimate key cosmological parameters.

## Objectives

- Construct the Hubble diagram
- Estimate the Hubble constant ($H_0$)
- Estimate the matter density ($\Omega_m$)
- Estimate the age of the Universe
- Analyze model residuals
- Compare low-redshift and high-redshift supernovae

## Methods

The project uses:

- Python
- Pandas and NumPy for data analysis
- Matplotlib for visualization
- SciPy for numerical integration and parameter fitting
- Flat ΛCDM cosmological model
